This project focuses on assisting farmers and agricultural stakeholders by providing intelligent crop recommendations based on soil nutrients and environmental conditions. The system leverages machine learning to suggest the most suitable crop, helping improve productivity and decision-making in agriculture.

🔹 Key Features:
• User registration and secure login system
• Input-based crop prediction using ML model (N, P, K, temperature, humidity, pH, rainfall)
• Display of recommended crop with images for better understanding
• Top 3 crop suggestions for alternative choices
• Prediction history dashboard with edit and delete options
• Downloadable PDF report of prediction results
• Email functionality to send crop recommendation and report
• Image integration for visual representation of crops

🔹 Technologies Used:
• Frontend: HTML, CSS, Bootstrap, JavaScript
• Backend: Flask (Python)
• Database: MySQL
• Machine Learning: Scikit-learn
• APIs/Tools: Pexels API (for crop images), SMTP (Email)
• Development Tools: VS Code

🔹 Project Highlights:
• Developed a complete full-stack web application with ML integration
• Implemented CRUD operations for prediction management
• Designed an interactive and user-friendly dashboard
• Integrated real-time image display for better visualization
• Generated automated PDF reports for users
• Built a scalable system combining AI and web technologies
This project provided valuable hands-on experience in machine learning integration, full-stack development, and building real-world agricultural solutions.
